# Arca

A local iOS notes app.

<br>

## Description

Arca is a notes app... to take notes, obviously. Built to keep everything in
sync across devices.

Notes are rich text: paragraph styles, bold, italic, and links. Sizes come from
the system text styles, so everything scales with Dynamic Type.

Decided to build this because I wanted to learn Swift/SwiftUI and the native
iOS notes app is ass.

**Status: early.** The editor is the only part built so far.
